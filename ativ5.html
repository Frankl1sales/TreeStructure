🌲 A Árvore dos Animais

Imagine uma árvore onde cada galho representa um grupo de animais:

💻 Sua Missão de Programação

🌳Você precisa corrigir o erro neste código para usar o nome correto (que é o mistério), que pode estar em qualquer ordem taxonômica.🎉


  // Implemente sua função de busca aqui
  function searchNode(root: Node | null, target: string): Node | null {
    // 1º: Se a árvore estiver vazia, retorne null
    if (root === null) return null;
    
    // 2º: Se achou o animal, retorne ele!
    if (root.data === target) return root;
    
    // 3º: Procure no galho esquerdo
    const leftResult = searchNode(root.left, target);
    if (leftResult !== null) return leftResult;
    
    // 4º: Se não achou, procure no galho direito
    const rightResult = searchNode(root.right, target);
    return rightResult;
  }

  // Depois chame a função para buscar um animal:
  const targetNode = searchNode(rootNode, "Mammalia");

📝 Passo a Passo

  1. A função recebe a raiz da árvore e o nome do animal a ser encontrado
  2. Ela verifica se o animal está no nó atual
  3. Se não estiver, procura nos galhos da esquerda e depois da direita
  4. Quando encontrar, retorna o nó com o animal

🌟 Dica Importante

A função chama a si mesma para procurar nos galhos - isso se chama RECURSÃO! É como se você pedisse para um amigo procurar em cada parte da árvore.

🔹 Se acertar, aparecerá um quadrado vermelho no animal encontrado!

🔹 Se errar, o computador vai te avisar para tentar de novo!
