Nesta atividade, você vai ajudar a encontrar e remover animais escondidos em uma árvore genealógica da floresta usando programação! 🕵️‍♂️🔍

🌲 A Árvore dos Animais

Imagine uma árvore onde cada galho representa um grupo de animais:

💻 Sua Missão de Programação

Você precisa implementar duas funções: 🌳Buscar um nó na árvore; ✂️ Remover um nó da árvore (quando encontrado)

🌳Função para buscar na árvore taxonômica.🎉


  // Implemente sua função de busca aqui
  function searchNode(root: Node | null, target: string): Node | null {
    // 1º: Se a árvore estiver vazia, retorne null
    if (root === null) return null;
    
    // 2º: Se achou o animal, retorne ele!
    if (root.data === target) return root;
    
    // 3º: Procure no galho esquerdo
    const leftResult = searchNode(root.left, target);
    if (leftResult !== null) return leftResult;
    
    // 4º: Se não achou, procure no galho direito
    const rightResult = searchNode(root.right, target);
    return rightResult;
  }

🌳Função para remover o nó na árvore taxonômica.🎉


  // Implemente sua função de remoção aqui
  function removeNode(root: Node | null, target: string): Node | null {
    // 1º: Se a árvore estiver vazia, retorne null
    if (root === null) return null;
    
    // 2º: Se o nó atual é o alvo, retorne null para removê-lo
    if (root.data === target) return null;
    
    // 3º: Atualize os filhos recursivamente
    root.left = removeNode(root.left, target);
    root.right = removeNode(root.right, target);
    
    return root;
  }

🌳Chamada das funções para buscar e remover o nó na árvore taxonômica.🎉

⚠️ IMPORTANTE: Encontre o (chamado de nó correto) ! 🧬🌍


  // Primeiro busque o nó

  // Depois remova o nó (se encontrado)
  if (targetNode) {
    rootNode = removeNode(rootNode, "xxxxx");
  }

📝 Passo a Passo para Remoção

  1. A função recebe a raiz da árvore e o nome do animal a ser removido
  2. Ela verifica se o animal está no nó atual
  3. Se for o alvo, retorna null para removê-lo
  4. Se não for, atualiza os filhos esquerdo e direito recursivamente
