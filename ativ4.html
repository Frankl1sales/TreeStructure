Descrição da Atividade

Na atividade proposta, você irá construir uma árvore que segue a classificação taxonômica de alguns animais. A árvore será do tipo:


Animalia
  └── Chordata
        ├── Mammalia
        │     ├── Primates
        │     │     └── Homo sapiens
        │     └── Carnivora
        │           └── Canis lupus
        └── Aves
              └── Passeriformes
                    └── Corvus corax

O objetivo é validar se a estrutura criada corresponde exatamente à esperada. Utilize o editor para criar sua árvore e clique em "Executar Código" para verificar sua solução.

Visual Esperado:

Por favor, siga as instruções abaixo para preencher o código completo no editor. Quando terminar, clique no botão "Executar" para visualizar a árvore binária gerada.

1. Definição do Nó

Primeiro, definimos a estrutura do nó. Nesta árvore específica, cada nó tem um valor (data), que nesse caso deve ser uma string, pois armazenará os nomes de cada ordem na árvore taxonômica. Além disso, cada nó possui dois ponteiros: um para o filho à esquerda (left) e outro para o filho à direita (right).


class Node {
    data: number;
    left: Node | null;
    right: Node | null;

    constructor(data: number) {
        this.data = data;
        this.left = null;
        this.right = null;
    }
}

2. Função para Criar a Árvore

Agora, criamos a árvore. Vamos definir uma função chamada createTree que criará a árvore com os seguintes nós:

1 será a raiz da árvore, 2 e 3 serão os filhos de 1 e 4 e 5 serão filhos de 2.


function createTree(): Node {
    const root = new Node(1);        // Raiz da árvore
    root.left = new Node(2);         // Nó esquerdo
    root.right = new Node(3);        // Nó direito
    root.left.left = new Node(4);    // Filho esquerdo do nó 2
    root.left.right = new Node(5);   // Filho direito do nó 2

    return root; // Retorna a árvore binária
}

⚠️ AVISO: O nome da propriedade "data" deve ser renomeado para representar os nomes de cada ordem na árvore taxonômica, de acordo com a estrutura hierárquica de classificação dos organismos. Isso garantirá que os valores da árvore reflitam corretamente a taxonomia. 🧬🌳

4. Executando o Código

Agora que você já tem as funções para definir o nó, criar a árvore, vamos executar o código completo para visualizar o resultado.

O próximo passo é criar a árvore utilizando a função createTree:


// Criando a árvore
