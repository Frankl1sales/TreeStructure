Explorando Árvores Binárias 🌳🐒

🧩 Vamos Construir Uma Árvore de Números!

Imagine que os números são como animais numa floresta, cada um com seu lugar especial. Vamos criar uma árvore onde cada número pode ter até dois "filhotes" (números menores ligados a ele).

🔍 Siga os passos abaixo para criar sua árvore digital. Quando terminar, clique em "Executar" para ver sua árvore ganhar vida!

📚 Como Funciona?

Toda árvore começa por uma raiz (o número principal). Cada número pode ter:

  • 👉 Um galho à esquerda (para números menores)
  • 👉 Um galho à direita (para números maiores)

É como uma família onde cada pessoa pode ter até dois filhos!

1️⃣ Primeiro Passo: Criando um Nó (o "animal" da nossa floresta)

Cada "animal" (nó) da nossa árvore tem:

  • 📝 Um valor numérico (data)
  • 🖇️ Um galho esquerdo (left)
  • 🖇️ Um galho direito (right)

class Node {
  data: number;       // O valor do nosso "animal"
  left: Node | null;  // Galho esquerdo (pode ser vazio)
  right: Node | null; // Galho direito (pode ser vazio)

  constructor(data: number) {
    this.data = data;
    this.left = null;   // Começa sem galho esquerdo
    this.right = null;  // Começa sem galho direito
  }
}

2️⃣ Segundo Passo: Plantando Nossa Árvore

Vamos criar uma árvore especial com estes números:

1
2
4
5
3

function createBinaryTree(): Node {
  // 🌱 Plantamos a raiz (o número 1)
  const root = new Node(1);
  
  // 🌿 Adicionamos o galho esquerdo (número 2)
  root.left = new Node(2);
  
  // 🌿 Adicionamos o galho direito (número 3)
  root.right = new Node(3);
  
  // 🍃 O número 2 tem dois galhos menores:
  root.left.left = new Node(4);   // Galho esquerdo do 2
  root.left.right = new Node(5);  // Galho direito do 2

  return root; // 🌳 Retorna nossa árvore completa!
}

3️⃣ Hora de Ver a Mágica Acontecer!

Agora vamos juntar tudo e ver nossa árvore:

  1. 1️⃣ Criamos a estrutura do nó
  2. 2️⃣ Construímos a árvore
  3. 3️⃣ Vamos mostrar o resultado!

// 🌱 Criamos a árvore binária
const rootNode = createBinaryTree();

// 🎉 Mostramos o ponto de partida (a raiz)
rootNode;
